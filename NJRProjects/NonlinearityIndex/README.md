# The Nonlinearity Index

A catalogue of activation functions for deep learning: formula, behaviour, and a plot of each curve
and its derivative, organised by family, plus a use-case guide to which functions get chosen for
which tasks and why.

It has 374 functions. About 290 of them come from the survey by Kunc & Kléma (2024),
[*Three Decades of Activations*](https://arxiv.org/abs/2402.09092), and are credited to it on each
card. Each implementation was checked numerically against the survey's formula at 41 points. Where
the survey's formula has a typo, the card gives the corrected form and says what changed. The
roughly 50 survey entries that can't be drawn as a single curve (stochastic, input-dependent or
layer-level functions) are listed on the site with the reason.

Plain HTML and CSS. The pages are generated by a small Python script (standard library only), so
every plot is a pre-rendered inline SVG; `public/app.js` only adds search, filters and the theme toggle.

## Layout

- `catalog.py`: the original functions, plus the list of survey entries that aren't drawn
- `catalog_survey.py`: the functions from the survey
- `use_cases.py`: the use-case guide (picks, the properties that matter, reasoning)
- `build.py`: generates `public/index.html` and `public/use-cases.html`
- `public/`: the deployed site (`styles.css` and `app.js` are hand-written)

## Adding a function

1. Append an `fn(...)` entry to `FUNCS` in `catalog.py` (the docstring at the top lists the fields).
2. Optionally reference its slug from a use case in `use_cases.py`.
3. Run `python3 build.py`. It validates slugs, families and properties, then rebuilds the pages. If
   `range` is left as `None`, the build estimates it by sampling and marks it with ≈. Smoothness and
   boundedness are computed the same way.
4. Run `python3 check.py`. It fails if any section count differs from the cards actually rendered,
   if an `#anchor` link on either page points to a missing id, or if a link-preview tag is missing.

The link-preview image `public/og-image.png` (1200×630) is rendered from `assets/og-image.html`;
the command to regenerate it is at the top of that file.

## Deploying

The Vercel project serves `public/` as static files (`vercel.json`). From this folder:

```
python3 build.py && python3 check.py && vercel deploy --prod
```
