# Activation Functions

Collaborative exploration of activation functions in neural networks, covering the range of functions available in `torch.nn` (and beyond), from foundational ones (ReLU, Sigmoid, Tanh) to more specialised and modern variants (GELU, SiLU, Mish and others).

The work is published as two websites: **The Nonlinearity Index** (https://nonlinearity-index.vercel.app) and **Neural Atlas** (https://neural-atlas-ten.vercel.app).

## Live sites

Both sites are static and hosted on Vercel.

| Site | What it is | Source |
| --- | --- | --- |

Includes a [use-case guide](https://nonlinearity-index.vercel.app/use-cases) to which functions get chosen for which tasks and why. 85 functions so far, growing toward ≈400. | [`NJRProjects/NonlinearityIndex/`](NJRProjects/NonlinearityIndex/) |
| [**Neural Atlas**](https://neural-atlas-ten.vercel.app) | A field guide to Machine Learning, Deep Learning and Reinforcement Learning: about 195 topics with formulas and code, three interactive labs, and a Python playground that runs 26 example programs in the browser. | [`NJRProjects/ML/main.html`](NJRProjects/ML/main.html) |

## Purpose

This repository is a joint deep-dive into *why* activation functions matter, not just *what* they do. Goals include:

- Understanding the mathematical behaviour of each function (shape, range, derivative)
- Comparing gradient-flow characteristics (for example, vanishing and exploding gradients)
- Identifying practical use cases and trade-offs (for example, why GELU is preferred in Transformers and why ReLU dominates CNNs)
- Hands-on implementation, both from scratch (plain Python/NumPy) and with `nn` built-ins
- Visualising function curves and their derivatives side by side

## ## Scope

Exploration spans the ~400 activation functions available in `torch.nn` and related libraries, prioritised by relevance and common usage rather than exhaustive coverage of every variant. The Nonlinearity Index tracks progress toward that number.

## Working on the sites

### The Nonlinearity Index

Plain HTML and CSS, generated by a small Python script that uses only the standard library. Every plot is pre-rendered as an inline SVG, so the pages work without JavaScript.

To add a function, append an entry to `catalog.py` (the fields are documented at the top of the file), optionally reference it from `use_cases.py`, then rebuild:

```bash
cd NJRProjects/NonlinearityIndex
python3 build.py            # validates the data and regenerates public/
vercel deploy --prod        # publishes public/ to nonlinearity-index.vercel.app
```

See [`NJRProjects/NonlinearityIndex/README.md`](NJRProjects/NonlinearityIndex/README.md) for details.

### Neural Atlas

A single self-contained file, `NJRProjects/ML/main.html`. Topics live in the `TRACKS` array in its script, and the runnable Python examples are the `<script type="text/x-python">` blocks near the end of the file. The playground runs them with [Pyodide](https://pyodide.org) (Python compiled to WebAssembly), so numpy, pandas, scikit-learn and matplotlib work in the browser; PyTorch does not.

To preview locally, serve the folder over HTTP rather than opening the file directly, because the playground's background worker needs it:

```bash
cd NJRProjects/ML
python3 -m http.server 8000     # then open http://localhost:8000/main.html
vercel deploy --prod            # publishes to neural-atlas-ten.vercel.app
```

Deploying either site needs access to the Vercel team that owns the projects.

## Approach

Work here follows the same style as the rest of the collaboration: concepts explained first, hands-on implementation second. Findings, comparisons and notebooks are split between individual exploration and joint synthesis as understanding develops.
